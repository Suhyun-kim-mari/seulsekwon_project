# 작업지시서: 서울시 슬세권 지수 시각화 대시보드 개발

이 문서는 `/Users/kimsuhyun/Desktop/fcicb6/seoul_seulsekwon/data/cleaned` 폴더에 마침내 정제된 생활 인프라 데이터를 기반으로, 서울시의 '슬세권(Lifestyle Convenience Zone)'을 입체적으로 분석하는 대시보드 개발을 위한 가이드라인입니다.

## 1. 프로젝트 배경 및 목적
- **배경**: 주거지 인근에서 누릴 수 있는 다양한 인프라의 질이 삶의 질과 연결됨
- **목적**: 정제된 12개의 인프라 데이터를 통합 지수화하여 지역별 편의성을 객관적으로 비교

## 2. 활용 데이터 소스 (12개 세트)

## 3. 핵심 기능 요구사항

### 3.1 기준점 설정 및 슬세권 지수(Seulsekwon Index) 산출
- **기준점 설정**: 사용자가 입력한 **주소 검색**을 통해 분석의 기준이 되는 위경도 좌표를 획득
- **좌표 변환**: **카카오 REST API**를 사용하여 주소(또는 장소명)를 위경도로 변환 (자세한 내용은 `docs/kakao_rest_api.md` 참고)
- **분석 단위**: 검색된 좌표 기준 반경 500m / 1km 이내 시설수
- **가중치 로직 (가이드)**:
  - **교통(30%)**: 지하철 비중 높게 설정
  - **생활/상권(25%)**: 스타벅스 및 소상공인 밀집도
  - **안전/공공(20%)**: 경찰, 병원, 은행
  - **문화/환경(25%)**: 공원, 서점, 도서관, 학교
- **정규화**: 각 항목별로 점수를 정규화(0~100)하여 최종적인 슬세권 지수 도출

### 3.2 대시보드 레이아웃 설계
- **사이드바(Sidebar)**: 
  - **주소 검색창 (최상단)**: 카카오 REST API 연동 주소 검색 입력창
  - 가중치 커스텀 조정 (드래그 바)
  - 시설 카테고리별 On/Off 스위치
  - 분석 행정구/행정동 선택
- **메인 시각화 영역**:
  - **공간 분석 지도**: 
    - Pydeck 기반의 Scatter 레이어로 전체 인프라 시각화
    - **기준점 표시**: 검색된 주소의 중심 좌표에 특수 마커(예: 크기가 크고 강조된 색상) 표시
    - **분석 반경 시각화**: 중심 좌표를 기준으로 설정된 반경(500m 또는 1km)을 나타내는 반투명한 원(Polyline 또는 ScatterLayer) 표시
    - **반경 내 시설 강조**: 설정된 반경 내에 포함되는 시설물들만 별도의 색상이나 크기로 강조하여 슬세권 범위 가시화
  - **지표 요약 레이아웃 (KPI Cards)**: 선택한 지역의 종합 점수와 서울시 평균 대비 수준 표시
  - **세부 등급 차트**: 5각형/6각형 형태의 방사형 차트(Radar Chart)로 지역별 인프라 밸런스 측정
  - **인근 정보 목록**: 지도 클릭 시 반경 내 주요 시설물 명단 노출

## 4. 개발 환경 및 외부 API 설정
- **가상환경**: 프로젝트의 독립성을 위해 **별도의 가상환경**(`venv` 또는 `conda`)을 구축하여 사용
- **카카오 REST API**:
  - `docs/kakao_rest_api.md`를 참고하여 `KakaoLocalHandler` 구현
  - REST API 키는 `.env` 파일에 안전하게 보관하여 사용
- **주요 라이브러리**: `streamlit`, `pandas`, `pydeck`, `requests`, `python-dotenv`

## 5. UI/UX 디자인 원칙
- **Vibrant & Intuitive**: 데이터의 밀도는 히트맵 계열의 선명한 색상으로 표현
- **Interactive**: 지도와 차트가 상호 연동되어야 함 (Cross-filtering)
- **Speed**: 대용량 상권 데이터를 효율적으로 렌더링하도록 최적화
